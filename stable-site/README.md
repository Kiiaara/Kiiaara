# Сайт конюшни

Одностраничный лендинг: чистые HTML/CSS/JS, без сборки. Языки: RU / EN / TR.

## Структура

```
stable-site/
├── index.html    — вся разметка и русский текст
├── styles.css    — оформление
├── script.js     — переводы EN/TR, меню, галерея-лайтбокс, анимации
├── favicon.svg
└── images/       — фотографии
```

## Фото

Положите в `images/` файлы с такими именами (или поменяйте `src` в `index.html`):

| Файл | Где | Совет |
|------|-----|-------|
| `hero.jpg` | первый экран на весь экран | горизонтальное, ~2400px по ширине |
| `about.jpg` | блок «О нас» | вертикальное 4:5 |
| `gallery-1.jpg` … `gallery-8.jpg` | галерея | 1 и 6 — вертикальные, 4 и 8 — широкие |

Перед загрузкой сожмите фото (например, на squoosh.app) до ~300–500 КБ — сайт будет быстро открываться с телефона.
Пока фото нет, на их месте видны аккуратные бежевые заглушки.

## Что заменить (ищите `TODO` в index.html)

- название конюшни (в `<title>`, логотипе, заголовке, подвале);
- номер WhatsApp (`wa.me/90...` — только цифры, с кодом страны) и телефон;
- ник Telegram и Instagram;
- адрес, часы работы и цифры в блоке «О нас»;
- карту (Google Maps → «Поделиться» → «Встраивание карт» → взять `src`);
- переводы для EN/TR — в `script.js`.

## Публикация на Cloudflare Pages

1. Cloudflare → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**, выбрать этот репозиторий.
2. Framework preset: **None**, Build command: пусто, **Build output directory: `stable-site`**.
3. После деплоя: **Custom domains** → добавить свой домен (если домен в Cloudflare, DNS настроится сам).

Альтернатива без Git: **Upload assets** и перетащить папку `stable-site`.
